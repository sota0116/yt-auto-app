yt-auto プライバシーポリシー

制定日：2026年10月24日

1. このツールについて

yt-auto（以下「本ツール」）は、作成者本人が持っている YouTube チャンネルの運用だけに使う、個人用のツールです。一般の方は利用できません。

2. 扱う情報

本ツールは、作成者本人が Google アカウントで許可した範囲で、次の情報を扱います。

  • YouTube チャンネルの情報（チャンネル名・ID）
  • YouTube の動画・サムネイル・タイトル・説明文・字幕・コメント
  • YouTube アナリティクスの数字（再生回数・視聴時間など）
  • 本ツールが Google ドライブに作ったファイル（ほかのファイルは扱いません）

3. 使い道

扱う情報は、作成者本人のチャンネルへの動画の投稿と予約、タイトルなどの更新、コメントの管理、数字の集計のためだけに使います。広告や、ほかの目的には使いません。

4. 保存と共有

ログインの情報は、作成者本人の PC と、作成者本人だけが使える非公開の保管場所に保存します。扱う情報を、第三者に売ったり渡したりすることはありません。

本ツールが Google API から受け取った情報の使い方は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

5. YouTube API サービスの利用

本ツールは YouTube API サービスを使っています。利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

6. アクセスの取り消し

本ツールへのアクセスは、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消すと、本ツールは情報を扱えなくなります。Google のセキュリティ設定のページからも取り消せます。
